# About 👤

Welcome to the Fresh Forensics OSINT Workshop. This repository contains the tools, commands, scripts, workflows, and resources used throughout the OSINT livestreams on the Fresh Forensics YouTube channel.

Each livestream is organized into its own directory and represents a chapter in the workshop. The goal is to document the actual workflows used during the livestreams so that you can follow along, reproduce the techniques, and experiment with the tools yourself.

# Workshop Structure 📂

Each livestream has its own directory containing the material from that investigation.

```text
OsintWorkshop/
├── Chapter01/
│   ├── README.md
│   ├── scripts/
│
├── Chapter02/
│   ├── README.md
│   ├── scripts/
│
└── ...
```

The structure may vary depending on the subject and tools covered in each livestream.

# Livestream Chapters 🎥

Each livestream becomes its own chapter in the workshop.

Every chapter contains the commands, scripts, tools, and workflow used during that particular livestream.

The goal is to make each investigation reproducible and easy to follow from the Linux terminal.

# Follow Along 🧭

Each chapter contains the commands and workflow used during that particular livestream. Rather than simply listing tools, the goal is to show how individual pieces of information can be connected together to build an OSINT investigation.

Start with a chapter directory and follow the README, commands, and scripts from beginning to end.

# Learn The Workflow 🧠

OSINT is more than running a single tool.

A username can lead to an email address. An email address can lead to a GitHub account. A repository can reveal commits, files, metadata, or other clues. A video can contain usernames, links, timestamps, metadata, and other breadcrumbs.

The workshop focuses on following those connections and building an investigation step by step.
